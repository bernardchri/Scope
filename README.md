# Scope V0.1
- Rendre les cahiers des specs techniques lisibles par tous et facile à écrire.

## Principe
- Création d'un cahier de specs techniques qui accompagnera le projet dès le début de projet, en passant par l'explications des maquettes, au suivi de la réalisation. 

### Objectif
- rendre facile à écrire un cahier des spescs pour les CDP
- rendre lisible un cahier des specs pour les developpeurs
- valider auprès d'un client un cahier des specs

### inspiration
- Storybook :  parce que l'on peut imaginer installer une scope par projet, et l'accoler aux fichiers de chaque projet web.
